## 0. 这份报告回答什么问题？

我们希望验证并量化：

- **晶体表面微粗糙**（`crystalSigmaAlpha = σ_α`）如何影响锁光/TIR 与自吸收；
- **侧/顶面贴合比例**（`p = sideContactRatio = topContactRatio`）如何改变 TIR（无损）与 PTFE（有损）之间的权衡；
- 在 **Grease 底耦合** 情况下，二维参数空间 \(p \times σ_α\) 的 **ε_col（到达 Si 的几何命中效率）**、以及各类光子损失通道如何变化；
- 结果是否符合理论预期（趋势与极限）。

本报告包含可复现实验脚本、完整数据 CSV、热力图与切片图，可直接转发。

## 1. 重要实现修正（决定趋势是否可信）

在本次 10×10 扫描前，我们根据流程图逐行审计并修正了两处会“系统性带偏结果”的实现细节（已进入代码）：

1. **`sc_gap -> World` 的 PTFE 拦截不能覆盖“底部开窗”通道**  
   - 旧：任何 `sc_gap -> World` 都被当成 PTFE 反射/吸收，等效“封窗”。  
   - 新：仅拦截 “侧/顶漏光进入 World” 与 “wrapper->World 外表面”；**底部开窗平面**（`wrapper_bottom_z` 附近）允许光子进入 World→grease→Si。

2. **概率边界法的面判别改为晶体局部坐标判别**  
   - 旧：用 global z 近似 bottomZ，可能把侧/顶/底面判错。  
   - 新：用 `touchable->GetHistory()->GetTopTransform()` 把边界点投到晶体局部坐标系，再以 `±halfX/±halfY/±halfZ` 判面。

这两处修正后，**“σ 足够大时，增大 p 会降低 ε_col”** 的趋势回归直觉预期，并且损失通道的变化也更自洽。

## 5. 现象与理论趋势对比（高层解释）

### 5.1 理论/直觉预期（趋势）

1. **σ_α 增大**：表面微面法线分布更宽 → 角度被打散 → 更易“解锁”困在 TIR 模式里的光 → 平均光程变短 → **晶体自吸收下降** → ε_col 上升（直到饱和）。

2. **在 σ_α 足够大时，增大 p 应更差**：  
   - p 增大意味着更多事件走“PTFE 概率边界”，替代原本可能发生的 TIR（无损）  
   - PTFE 每次接触都有 \((1-R)\) 的吸收概率（此处 R≈0.975），因此 **p 越大总体越差**  
   - 并且在 p=1 情况下，几何中还会启用 `dielectric_metal` 的 PTFE contact border surface，使 σ_α 的 dielectric_dielectric 粗糙表面被跳过，因此 **p=1 对 σ 不敏感**（应出现一条“几乎水平”的 σ 方向结果）。

3. **在 σ_α 很小（接近光滑）时，p 可能“看起来更好”或出现非单调**：  
   这是“锁光导致超长光程→自吸收大”与“PTFE 有损”的竞争，取决于材料吸收长度与反射次数统计。  
   本次修正后总体趋势更接近“σ 大时单调变差”。

### 5.2 与本次扫描结果的一致性（定性）

从热力图与损失通道热力图可以看到：

- σ 从 0 → 0.1/0.2：`Esc_CrystalAbsorbed` 明显下降，ε_col 显著提升（锁光被打破，自吸收减轻）
- 固定 σ≥0.1 时：p 从 0 → 1.0，`Esc_PTFE` 增大且 ε_col 下降（TIR 机会减少 + PTFE 吸收累积）
- p=1.0：ε_col 对 σ 基本不敏感（符合“contact mode 跳过 σ 表面”的实现/物理预期）

### 5.3 与闭式 sanity-check 理论的定量对照（关键锚点）

这里我们对照 `docs/main.md` 中已推导的闭式结果（同一折射率 \(n_1=1.86\)，底面介质为 grease \(n_2=1.46\)）：

- **场景 A（侧/顶完美镜面，底面真实 Fresnel+TIR；忽略吸收）**：
  \[
  \varepsilon_{\text{col}}^{(A,\text{grease})}
  =1-\sqrt{1-\left(\frac{n_2}{n_1}\right)^2}
  \approx 0.381
  \]
  对应我们网格中的 **极限点**：`p=0, σ=0`（最接近“锁光/TIR 极限”）。  
  Geant4：`ε_col=0.3829`（与 0.381 一致，差异在统计涨落量级）。

- **场景 C（侧/顶朗伯 + 常数反射率 \(R=0.975\)，底面为 grease；忽略晶体吸收）**：
  \[
  \varepsilon_{\text{col}}^{(C,\text{grease})}
  \approx 0.832
  \]
  对应我们网格中的 **“全贴合 PTFE contact”**：`p=1.0`（此时几何启用 `dielectric_metal` 接触面，且 σ 表面被跳过）。  
  Geant4：`p=1.0` 这一列在 10 个 σ 点上 **几乎不变**，均值 `0.8503`，标准差 `0.00143`。  
  该差异（约 +0.018）主要可归因于：本系统的“底面命中概率”并不严格等于理论 mean-field 取的 \(p_b=1/6\)，以及几何边界/真实轨迹并非理想“每次完全重新独立抽样”的假设。

> 结论：用 `docs/main.md` 的闭式 sanity-check 作为锚点时，我们的 Geant4 实现能够在关键极限点上给出一致的数量级与正确趋势；而二维网格扫描主要用于描述“有限吸收长度 + 表面粗糙 + 概率贴合”共同作用下的系统行为。

## 6. 给理论同事的结论（可直接引用）

1. 在 Grease 耦合下，**表面粗糙度 σ_α 是抑制锁光/降低自吸收的关键旋钮**；σ 从 0 增大到 ~0.1 rad 左右时，ε_col 显著提升并趋于饱和。

2. 在 σ_α 足够大（已能打散角度）的前提下，**增大贴合比例 p 会把无损 TIR 替换为有损 PTFE 交互，因此 ε_col 随 p 增大而下降**，并且 PTFE 吸收通道占比显著上升。

3. 本次扫描前修正了两处实现细节（底部开窗通道与面判别），修正后趋势与上述理论预期一致；同时保留了每个点的损失通道统计，便于后续把模型压缩成“理论有效参数”（例如等效反射次数、等效平均光程等）。
