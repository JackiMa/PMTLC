## 1. 核心发现摘要

Geant4 仿真结果 **系统性高于理论上界 M1**，主要原因：

| 因素 | 理论假设 | Geant4 实际 | 影响 |
|------|----------|-------------|------|
| air-gap 逃逸 | M1: 100% 回收 | PTFE wrapper 回收 (R=97.5%) | 接近 M1 |
| 底面命中概率 | p_b = 1/6 | **可能更高**（见分析） | ε_col ↑ |
| 晶体自吸收 | **忽略** | 7-41%（取决于 σ） | ε_col ↓ |
| sideContactRatio p | 概率边界法 | **未实现**（仅支持 p=0 或 p=1） | 无法直接对照 |

## 3. 自吸收效应分析

### 3.1 表面粗糙度 vs 自吸收率

| σ_α (rad) | ε_col | 被吸收 | 吸收率 | 备注 |
|-----------|-------|--------|--------|------|
| 0.0 | 0.490 | 4096 | **40.9%** | 困光导致极长光程 |
| 0.05 | 0.855 | 827 | 8.3% | 打破困光 |
| 0.1 | 0.857 | 818 | 8.2% | 正常工作点 |
| 0.2 | 0.868 | 780 | 7.8% | |
| 0.5 | 0.887 | 722 | 7.2% | |
| 1.0 | 0.893 | 697 | 7.0% | 接近极限 |

### 3.2 平均光程估计

GAGG 在 530nm 处的吸收长度：**L_abs ≈ 400 mm**

```
吸收概率 = 1 - exp(-L_path / L_abs)

σ=0 (困光): L_path >> 100mm → P_abs ≈ 22-50%
σ>0 (正常): L_path ≈ 10-30mm → P_abs ≈ 2.5-7%
```

### 3.3 吸收长度缩放扫描（验证自吸收效应）

使用 550nm 固定波长光子，扫描 GAGG 吸收长度缩放因子：

| scaleFactor | L_abs | ε_col | 晶体吸收 |
|-------------|-------|-------|---------|
| 0.1 | L/10 | 52.7% | 42.6% |
| 0.5 | L/2 | 80.2% | 13.5% |
| **1.0** | **原始** | **85.9%** | **7.3%** |
| 2.0 | L×2 | 89.0% | 3.9% |
| 10.0 | L×10 | 91.9% | 0.7% |
| 100.0 | L×100 | **92.4%** | 0.04% |

**关键发现**：
- 原始 GAGG 自吸收导致 ~7% 效率损失
- 理想极限（无吸收）：92.4%
- 仿真与理论公式 $P_{abs} = 1 - e^{-L_{path}/L_{eff}}$ 吻合

### 3.4 对理论模型的修正建议

理论模型应引入自吸收修正因子：

$$\varepsilon_{\text{col}}^{\text{corrected}} = \varepsilon_{\text{col}}^{\text{theory}} \times (1 - P_{\text{abs}})$$

其中：
- $L_{eff} \approx 285$ mm（GAGG 发射光谱加权平均吸收长度）
- $L_{path} \approx 24$ mm（从 σ=0.1 的实验反推平均光程）
- $P_{abs} = 1 - e^{-L_{path}/L_{eff}} \approx 8\%$

## 5. 终态通道分析

从 `run_data.csv` 的典型输出：

```
Photon Hit si:     8573 (85.7%)
CrystalAbsorbed:    818 (8.2%)
Escaped_TopAir:       0 (0.0%)  ← 关键！
Escaped_SideAir:      0 (0.0%)  ← 关键！
Escaped_PTFE:         0 (0.0%)
Escaped_Other:      609 (6.1%)
```

**关键发现**：`Escaped_TopAir = Escaped_SideAir = 0`

这意味着：
- 光子透射进入 air-gap 后，**没有逃逸到外界**
- 被 PTFE wrapper 的 `G4LogicalSkinSurface`（R=97.5%）捕获并反射回晶体
- 这解释了为什么 G4 结果高于 M1（理论假设 air-gap 区 100% 回收，但实际被 PTFE 吸收约 2.5%）

## 7. 概率边界方法 (0 < p < 1) 的实现与验证

### 7.1 实现方案（已完成 2024-12-23）

使用 **极小 sideGap (1μm)** 方案，在 `SiPINLCSteppingAction` 中实现：

```cpp
// 检测光子从晶体进入 sc_gap
if (crystalToGap && 0 < p < 1) {
    // 判断侧面/顶面
    G4bool isTopFace = (pos.z() > zTop - 0.1 * crystalHeight);
    G4double p = isTopFace ? g_top_contact_ratio : g_side_contact_ratio;
    
    if (rand < p) {
        // 抽中贴合：PTFE 漫反射 (R=97.5%)
        if (randR < R) {
            // 反射：朗伯漫反射回晶体
            newDir = SampleLambertianHemisphere(normal);
        } else {
            // 吸收
            Kill and count as Escaped_PTFE;
        }
    }
    // 若 rand >= p：正常进入 air-gap
}
```

### 7.2 扫描结果（简化模型 2024-12-23）

| p | ε_col | 晶体吸收 | PTFE 吸收 | 说明 |
|---|-------|---------|----------|------|
| 0.0 | 85.9% | 733 | 0 | TIR + wrapper (R=97.5%) |
| 0.2 | 84.7% | 733 | 196 | TIR + 部分透射被 PTFE 吸收 |
| 0.5 | 81.7% | 708 | 484 | TIR + 更多透射被 PTFE 吸收 |
| 0.8 | 79.9% | 687 | 725 | TIR + 大部分透射被 PTFE 吸收 |
| 0.99 | 78.4% | 700 | 877 | TIR + 几乎全部透射被 PTFE 吸收 |
| **1.0** | **78.9%** | **1990** | 0 | BorderSurface (绕过 TIR!) |
| 2.0 | **91.7%** | 723 | 0 | BorderSurface (R=100%) |

### 7.3 物理解释

**重要：p<1 和 p=1 的物理过程根本不同！**

1. **p=0（TIR + wrapper）**：ε_col = 85.9%
   - 入射角 > θ_c：TIR 无损反射
   - 入射角 < θ_c：透射进入 air-gap，被 wrapper 反射（R=97.5%）
   
2. **0 < p < 1（简化模型）**：ε_col 随 p 缓慢下降
   - **TIR 仍然正常发生**（大部分光子无损反射）
   - 透射光子以概率 p×(1-R) 被额外吸收
   - 实现限制：无法正确模拟"跳过 TIR"的场景
   
3. **p=1（BorderSurface）**：ε_col = 78.9%
   - 使用 `dielectric_metal` 表面，**绕过 TIR**
   - 所有光子都是漫反射（R=97.5%）或吸收（2.5%）
   - 晶体吸收高（1990）因漫反射导致长光程

4. **p=2（BorderSurface, R=100%）**：ε_col = 91.7%
   - 理想漫反射，打破困光
   - 效率最高

### 7.4 当前实现的限制

**概率边界法的简化处理**：由于 Geant4 的 SteppingAction 在 TIR 发生之后才被调用，
当前实现无法正确模拟"以概率 p 跳过 TIR"的物理场景。实际实现是：
- 对于透射光子：以概率 p 增加 PTFE 吸收
- 对于 TIR 光子：不受影响

这导致 p=0.99 和 p=1.0 的物理过程不同：
- p=0.99：TIR 仍发生，只有透射光子被额外吸收
- p=1.0：TIR 被绕过，所有光子都是漫反射

**建议**：
- 对于理论对照，使用 p=0 和 p=1 的极限情况
- 0<p<1 的概率边界法结果仅供参考
